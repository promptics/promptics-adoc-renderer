= AsciiDoc Project Renderer
Promptics · 2025-11-18
:toc: macro
:icons: font
:source-highlighter: rouge

A generator toolkit for turning AsciiDoc projects into PDF or HTML, complete with Mermaid / PlantUML diagram support, theme customization, automatic font management, and optional linting.

toc::[]

== Requirements

- Bash (Unix-like shell)
- Ruby with `asciidoctor`, `asciidoctor-pdf`, `asciidoctor-diagram`
- Java (for PlantUML)
- Node-based `mmdc` (for Mermaid)
- Optional: `fc-list`, `asciidoctor-lint`

== Directory Structure

[source]
----
project-root/
├── doc-renderer/
│   ├── generate.sh
│   ├── promptics-theme.yml
│   ├── fonts/          # auto-managed; populated on demand
│   └── plantuml.jar    # downloaded automatically when needed
├── docs/
│   └── index.adoc
└── …
----

== Usage

[source,shell]
----
chmod +x doc-renderer/generate.sh
./doc-renderer/generate.sh
----

Common options:

- `-i`, `--input`: input directory (default: `../docs` relative to `doc-renderer/`)
- `-t`, `--theme`: theme file (default: `promptics-theme.yml`)
- `-o`, `--output`: output file path (defaults to `<index>.<format>`)
- `-x`, `--index`: main AsciiDoc file (default: `index.adoc` or the sole `.adoc` file)
- `--format`: `pdf` (default) or `html`
- `--dry-run`: verify tooling, fonts, and dependencies without generating output
- `--debug`: emit verbose diagnostic information

Example:

[source,shell]
----
./doc-renderer/generate.sh -i ./docs -t doc-renderer/promptics-theme.yml --format html --debug
----

== Features

- Auto-detects main AsciiDoc file
- Renders embedded `[plantuml]` and `mermaid` diagrams
- Generates PDF or HTML
- Verifies required tools and fetches missing ones when possible
- Downloads PlantUML JAR on demand
- Auto-discovers fonts referenced in the theme and downloads them if absent
- Optional linting with `asciidoctor-lint`
- Warns on missing images or diagrams

== Notes on Fonts

- Fonts referenced in `promptics-theme.yml` are stored under `doc-renderer/fonts/` and are downloaded automatically from the upstream source if missing.
- You generally do *not* need to commit the populated `fonts/` directory; allow the script to manage it per environment.
